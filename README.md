# 🏠 Home Lab Documentation – Security & Monitoring Lab

This repository contains the full documentation of my personal cybersecurity home lab.  
It covers network architecture diagrams, Active Directory labs, SIEM configurations, hardening procedures, and monitoring setups.

The goal of this lab is to simulate real enterprise environments in order to practice:
- SOC workflows  
- Threat detection  
- Hardening techniques  
- Logging and monitoring  
- Windows & Linux security  
- Incident response scenarios  

---

## 📂 Repository Structure

### 📁 `network-diagrams`
Network topologies and architectural diagrams for different lab setups.

### 📁 `active-directory-lab`
Documentation for building a Windows AD environment and testing common attacks.

### 📁 `siem-setup`
Configuration notes for tools such as Wazuh, Elastic Stack, Sysmon, and log pipelines.

### 📁 `linux-hardening`
Hardening guides focused on securing Linux machines in the lab.

### 📁 `windows-hardening`
Windows security configuration, including GPO, Sysmon, and logging practices.

### 📁 `home-network-monitoring`
Analysis of home-network traffic and IDS/IPS configurations.
